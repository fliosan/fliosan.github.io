# shahzod.dev — Pocket Theater

Personal portfolio of **Shahzod Abdujabborov**, senior Flutter / iOS / Android engineer.

The page behaves like an iOS session: CSS-drawn iPhones run live coded demos of my shipped apps,
a Dynamic Island is the navigation, skills are Settings toggles, and contact is an iMessage thread.

- **Live:** https://fliosan.github.io/
- Hand-rolled vanilla HTML/CSS/JS — zero frameworks, no build step (`docs/`)
- Press `D` on the site for the Flutter-style widget inspector 🕵️

Also deployable to Cloudflare Workers: `npx wrangler deploy`
